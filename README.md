# Fonti

**Free Unicode font generator — type once, copy and paste 350+ styles anywhere.**

[fonti.cool](https://fonti.cool) · [Report a bug](https://fonti.cool/contact/)

## What it does

Fonti turns plain text into styled Unicode text — bold, italic, cursive,
gothic, bubble, small caps and more — that you can copy and paste into
Instagram bios, TikTok captions, Discord names, Steam profiles and gaming
tags. Nothing is generated as an image or a font file; every style is made
of real Unicode characters, so it survives copy and paste anywhere plain
text works.

## Why it's different

Most font generator sites list every style as if it works everywhere. Fonti
doesn't. Every style is labelled with where it actually breaks — older
phones, specific apps, screen readers — based on real device testing, not
guesses.

- **350+ styles** across cursive, bold, bubble, gothic, glitch, aesthetic and more
- **Platform guides** for Instagram, TikTok, Discord, Facebook and PUBG that
  show exactly which field accepts styled text and which doesn't
- **No signup, no tracking** — text is converted entirely in your browser
- **Honest compatibility labels** instead of "works everywhere" claims

## Tech stack

Built with [Astro](https://astro.build), static output, hosted on
Cloudflare Pages. No backend, no database, no JavaScript framework runtime —
just fast, static HTML.
